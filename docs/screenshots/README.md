Screenshots directory for Bookmrk docs

Place your screenshots in this folder and reference them from the top-level README.md.

Suggested filenames and sizes:

- home-4-up.png — 1600x900 (home page with 4-column grid)
- quick-save-modal.png — 800x600 (Quick Save modal open)
- board-settings.png — 800x600 (Board Settings modal)
- background-modal.png — 800x600 (Background modal)
- flow-quick-save.png — 1200x600 (Annotated flow diagram)

Tips:
- Use PNG for crisp UI; JPEG for photographic backgrounds to reduce file size.
- Try to keep each image under 300 KB to keep the repo light.
- Add a short caption in the README near each image when embedding.
